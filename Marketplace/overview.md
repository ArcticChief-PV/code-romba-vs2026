# CodeRomba

CodeRomba is an open-source Visual Studio extension that cleans up, reorganizes, and
formats your code — C#, C++, F#, VB, PHP, PowerShell, R, JSON, XAML, XML, ASP, HTML,
CSS, LESS, SCSS, JavaScript, and TypeScript.

It is a recovered and upgraded fork of the original
[CodeMaid](https://github.com/codecadwallader/codemaid) extension,
**originally created by Steve Cadwallader**, updated to support Visual Studio 2026.

## Features

- **Cleaning** — remove/insert whitespace, blank-line padding, and explicit access
  modifiers; run using-statement cleanup; apply file headers.
- **Reorganizing** — reorder members by type and accessibility, optionally inside regions.
- **Formatting** — comment formatting and wrapping.
- **Digging (Spade)** — a tree view of the current file's members for quick navigation.
- **Cleanup on save** — optionally clean files automatically when you save.

## Getting started

Install the extension, then use the **Extensions → CodeRomba** menu, or right-click in
the editor to run cleanup on the active document.
