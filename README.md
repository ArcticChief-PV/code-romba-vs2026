# CodeRomba

CodeRomba is an open-source Visual Studio extension that cleans up, reorganizes,
and formats your code — C#, C++, F#, VB, PHP, PowerShell, R, JSON, XAML, XML,
ASP, HTML, CSS, LESS, SCSS, JavaScript, and TypeScript.

It is a recovered and upgraded fork of the original
[CodeMaid](https://github.com/codecadwallader/codemaid) extension,
**originally created by Steve Cadwallader**, updated to support Visual Studio 2026.

Now maintained by WinterbiteStudios. All namespaces have been updated to reflect
WinterbiteStudios per the terms of the LGPL v3 license.

## Supported Visual Studio versions

- **CodeRomba** — Visual Studio 2019 / 2022 (`[16.0, 18.0)`)
- **CodeRomba.VS2026** — Visual Studio 2026 (`[18.0, 19.0)`)

## Building

Open `CodeRomba.sln` in Visual Studio with the *Visual Studio extension
development* workload installed, then build the solution.
